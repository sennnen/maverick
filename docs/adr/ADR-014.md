# ADR-014 — Additive stream kinds for the WHOOP gen5 K=18 record

## Context

The WHOOP 5.0/MG per-second history record (type 47, version 18) carries more physiological fields
than the first admitted decoder surfaced. Decoding the full record — corpus-pinned against real
captures imported from `tanarchytan/whoop-rs` `[WRS]` — produces two field kinds the frozen
`StreamKind` vocabulary could not yet name:

- a device-computed **SpO2 percentage** (the sleep-only tri-mode byte at inner 74). This is a
  finished 0–100 % value, not the unscaled optical ADC that `StreamKind::Spo2Raw` already covers
  (the gen4 v24 red/IR pair). Folding a percentage into `Spo2Raw` would erase the distinction
  between a raw count and a computed percentage, which downstream analytics must not confuse.
- a device-classified **coarse activity code** (0 still / 1 walk / 2 run at inner 55). No existing
  kind carries an activity classification.

`mav-model` is a frozen interface (CLAUDE.md), so even an additive change to its type vocabulary is
recorded here before it lands, per the model's own rule that renaming or removing a kind needs an
ADR while adding one is additive and safe.

## Decision

Add two `StreamKind` variants, `Spo2Percent` and `ActivityClass`, as additive members of the
existing enum. They are the raw on-wire values with a physiological gate at decode (SpO2 kept only
in 70..=100 %, activity only in {0,1,2}); they are not Maverick physiological claims. No existing
variant is renamed, reordered by meaning, or removed, so no serialized form changes and no stored
data migrates. The K=18 decoder emits these kinds only for admitted, corpus-pinned offsets, under
ADR-009; the empirical PPG SIGPROC bitfield (`signal_flags`, inner 25) has no clean kind and stays
recorded in the ledger rather than force-fit onto `WristState`.

## Consequences

Connectors may now advertise `spo2_percent` and `activity_class` capabilities, and analytics may
require them, without conflating a percentage with a raw ADC count. The additions are backward
compatible: older captures and snapshots decode unchanged, and the only exhaustive `match` on
`StreamKind` (mav-sqi's scorer) carries a wildcard arm, so both kinds score `unassessed` until a
signal-quality rule exists for them. The cost is the usual frozen-interface tax — the vocabulary
grows by ADR, not by convenience — which is the intended friction.
